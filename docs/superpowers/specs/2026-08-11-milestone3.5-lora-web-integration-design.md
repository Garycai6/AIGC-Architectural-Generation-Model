# 建筑 AIGC 生成模型 — 里程碑3.5:LoRA 接入网页生成设计

日期:2026-08-11
状态:已确认

## 背景与定位

里程碑3 训出了 4 个独立风格 SDXL LoRA(`.safetensors`,modern/neoclassic/european/nordic)。下期把 LoRA 挂到网页生成流程:网页 replicate 模式的效果图按风格注入对应 LoRA,使效果图更贴近训练风格、缓解 SDXL 固有幻觉。

## 已确认的关键决策

- **运行路径**:A — 自托管权重 URL + 推理注入(复用 AutoDL 已训产物,零额外训练费)
- **接入范围**:仅效果图接 LoRA(线稿 ControlNet 条件 + 风格 LoRA),平面图仍退回模拟器(SDXL 不适合平面图,已验证)
- **模型切换**:模型名配置化(Settings.sdxl_model),默认仍 `controlnet-sdxl` 不变,换模型由配置决定
- **验证**:本期真调(需 REPLICATE_API_TOKEN + 公网权重 URL,模式同里程碑3 阶段3)

## 关键事实(调研确认)

- Replicate SDK **无上传权重方法**;权重必须放在公网 URL
- SDXL 推理注入 LoRA 的字段名是 `replicate_weights` 或 `lora_weights`(视模型),数据形态为 tar/URL
- **LoRA 权重格式**:Replicate 的 LoRA 注入需 tar 打包(内含 `lora.safetensors`,可选 `embeddings.pti`/`special_params.json`),裸 `.safetensors` 不直接被认——里程碑3 产物是裸 `.safetensors`,接入前需打包重命名(`lora.safetensors`)并上传
- 现有 `replicategithubwc/controlnet-sdxl` 无 LoRA 字段,需换带 `lora_weights` 的 ControlNet 模型(如 `fermatresearch/sdxl-controlnet-lora`,未真调,效果待验证)
- 本地 `ApiGenerator` 用 `client.run(model, input={...})` 同步调用

## 架构

```
Settings.image_provider = "replicate"
  └── ApiGenerator(replicate_client, model=<配置>, lora_urls=<风格→URL>)
        └── generate(params) → _render_facade_sdxl
              └── _call_sdxl(prompt, control, out, lora_url=<按 style 查表>)
                    └── client.run(model, input={..., "lora_weights": lora_url})  # 若配置
```

## 组件改动

### 1. `generation/generators/api/replicate_gen.py`

- `ApiGenerator.__init__` 加可选参数 `lora_urls: dict[str, str] = {}`(风格 → 公网权重 URL),存 `self._lora_urls`
- `_call_sdxl` 加可选参数 `lora_url: str | None = None`;非 None 时注入 `"lora_weights": lora_url`
- `_render_facade_sdxl` 按 `params.style` 从 `self._lora_urls` 查 URL;查不到则传 None(该风格不注入,降级不报错)
- 模型默认值仍 `SDXL_MODEL`(向后兼容)

### 2. `backend/app/core/config.py`(Settings 新增字段)

```python
sdxl_model: str = ""          # 带 LoRA 的模型名,空=用默认 SDXL_MODEL
lora_weights_dir: str = ""    # 风格 LoRA 权重公网 URL 目录,空=不注入
```

### 3. `backend/app/api/generate.py`

- `image_provider == "replicate"` 时,若有 `lora_weights_dir`,组装 `lora_urls = {style: f"{dir}/{style}.tar"}`;模型用 `settings.sdxl_model or SDXL_MODEL`
- 构造 `ApiGenerator(replicate_client, model=..., lora_urls=lora_urls)`

## 测试策略

- `ApiGenerator` 构造 + `_call_sdxl` 注入逻辑 mock client 单测:
  - 配置 lora_urls 时,`client.run` 收到 `lora_weights=<style_url>`
  - 未配置时,`client.run` 不收 `lora_weights`(向后兼容)
  - 风格查不到 URL → 该风格不注入(降级不报错)
- 真调验证:手动,需 token + 公网 URL,记录到 smoke-test.md
