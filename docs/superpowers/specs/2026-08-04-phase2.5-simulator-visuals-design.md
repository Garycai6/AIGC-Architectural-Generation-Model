# 阶段 2.5:模拟器视觉差异化 — 设计规格

日期：2026-08-04
状态：已确认
前置：阶段 2 已合并到 master(参数→3/4 透视→平面→API→前端闭环)

## 背景与定位

阶段 2 建立了完整出图闭环,但存在两处视觉缺陷(最终审查记录):
- `FacadeSpec.roof` 字段存在但 renderer 从不读取 → 三种屋顶(flat/pitched/hipped)视觉完全相同
- `BuildingParams.style` 根本没传进 `build_facade_spec` → 四种风格(modern/neoclassic/european/nordic)视觉完全无差异,仅材质区分

本阶段目标:**让 roof 与 style 参数真正影响渲染输出**,提升模拟器视觉质量与护城河价值,为后续 ControlNet 线稿喂图提供更丰富的程序化条件图。

## 关键决策(已确认)

| 决策点 | 结论 |
|---|---|
| 屋顶深度 | 写实屋顶(屋脊/檐口/挑檐),重写顶面/侧壁投影逻辑 |
| 风格差异维度 | 窗型 + 檐口 + 配色 |
| 配色逻辑 | 风格叠加材质(确定性规则) |
| 风格实现 | 每个风格独立子类(策略模式),`STYLE_REGISTRY` 仅做字符串→子类工厂映射 |
| 验证方式 | 确定性断言(不同 roof/style 生成不同 FacadeSpec) |
| 架构风格 | 数据模型驱动:FacadeSpec 升级携带全部视觉信息,renderer 零风格分支 |

## 架构

### facade.py 升级(核心)

```
generation/generators/simulator/facade.py
├── RoofGeometry(BaseModel)      # 屋脊线 + 坡面多边形 + 檐口挑檐
├── CorniceSpec(BaseModel)       # 檐口:有无、厚度、y 位置
├── WindowRect(BaseModel)        # 升级:窗型由 build 决定(横长/竖/拱)
├── MaterialPalette(BaseModel)   # 不变
├── StyleConfig(ABC)             # 抽象基类:窗型规则 + 檐口规则 + 配色规则
│   ├── ModernStyle              # 横长窗 / 无檐口 / 中性偏冷
│   ├── NeoclassicStyle          # 对称竖窗 / 厚檐口+山花 / 暖灰
│   ├── EuropeanStyle            # 拱形窗 / 细檐口+山花 / 暖调
│   └── NordicStyle              # 小窗 / 木色薄檐口 / 低饱和
├── STYLE_REGISTRY: dict[str, type[StyleConfig]]   # 字符串→子类工厂映射
├── build_facade_spec(params) -> FacadeSpec        # 按 params.style 实例化子类
└── FacadeSpec 升级             # 携带 roof_geom + cornice + style + 升级后的 windows/palette
```

### renderer.py 升级

```
generation/generators/simulator/renderer.py
├── _draw_roof(draw, spec)       # 读 spec.roof_geom 几何画屋顶(三种形态)
├── _draw_cornice(draw, spec)    # 读 spec.cornice 画檐口
├── _draw_window(draw, window)   # 窗型在 WindowRect 中表达,统一绘制(含拱形)
└── _draw_facade_perspective 升级 # 重写顶面/侧壁:按 roof_geom 构建多边形,替换硬编码平顶
```

renderer **零风格分支**——只读 `spec.roof_geom`/`spec.cornice`/`WindowRect` 画出来,不知道 "modern" 是什么。

## 风格子类职责(StyleConfig)

每个风格子类覆写:
- `window_ratio`(宽:高)—— 决定窗型
  - modern:3:1 横长窗;neoclassic:1:2 对称竖窗;european:1:1.5 拱形窗;nordic:1:1 紧凑小窗
- `cornice()` -> CorniceSpec —— 檐口配置
  - modern:无;neoclassic:厚檐口 + 山花三角楣;european:细檐口 + 山花;nordic:木色薄檐口
- `apply_palette(material_palette) -> MaterialPalette` —— 风格叠加材质配色(确定性变换)

新增风格 = 加一个子类 + `STYLE_REGISTRY` 注册一行,不碰 renderer。

## 屋顶几何(写实)

`build_facade_spec` 按 `params.roof` 生成 `RoofGeometry`:
- **flat**:平顶 + 细檐口挑檐线
- **pitched**:前景山墙三角 + 坡面(顶面两斜面)+ 屋脊线
- **hipped**:四坡梯形顶 + 屋脊线(顶面梯形坡面)

`_draw_facade_perspective` 重写顶面/侧壁逻辑,为每种 roof 构建对应多边形(含屋脊/檐口/挑檐)。

## 数据流

```
BuildingParams { style, roof, materials, ... }
  → build_facade_spec(params)
      ├─ STYLE_REGISTRY[style]() 实例化风格子类
      ├─ 子类.window_ratio + cornice + apply_palette(materials) 生成
      ├─ params.roof → RoofGeometry
      └─ 产出升级版 FacadeSpec
  → renderer._draw_facade_perspective
      ├─ _draw_roof(spec.roof_geom)
      ├─ _draw_cornice(spec.cornice)
      └─ _draw_window(各 WindowRect)
  → facade.png(视觉差异化)
```

## 测试策略(确定性断言)

- `build_facade_spec(roof="flat")` vs `build_facade_spec(roof="pitched")` vs `hipped` → `roof_geom` 几何不同(断言多边形/屋脊线存在且不同)
- 四风格 `build_facade_spec` → 窗宽高比/檐口配置不同(断言 `window_ratio`、`cornice` 差异)
- 风格叠加材质 → `palette.main` 随风格与材质确定性变化(断言不同组合产不同色)
- 渲染冒烟:各风格各屋顶组合生成 PNG 非空、尺寸正确
- 现有 33 测试全部保持通过(regression)
